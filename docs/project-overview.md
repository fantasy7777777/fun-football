# Project Overview

## Purpose

Fun Football is a personal project for exploring Australian football market data through software, statistics, and AI-assisted development.

## Initial scope

- Represent football competitions, fixtures, teams, and outcomes.
- Import data from approved public or licensed sources.
- Normalise different source formats into a common schema.
- Compare historical and current published prices as a data-analysis exercise.
- Record data quality, timestamps, and source provenance.

## Out of scope

- Accepting payments or transactions.
- Operating user accounts with external providers.
- Providing personalised recommendations.
- Presenting theoretical analysis as a guarantee or financial advice.
- Publishing restricted, scraped, or unlicensed datasets.

## Future exploration

Possible future work includes probability models, scenario analysis, AI-assisted analysis, security testing, and deployment experiments. Each addition should remain consistent with the project scope and applicable data-source terms.
