# Fun Football

Fun Football explores Australian football market data for practice, research, fun, and curiosity. AI agents help build tools to organise and analyse public or properly licensed data.

The project does not accept transactions, operate accounts, provide recommendations, or aim to generate profit. All results are theoretical.

## Project layout

- `src/` — application and analysis code
- `tests/` — automated tests
- `data/raw/` — local source data; ignored by Git
- `data/processed/` — local derived data; ignored by Git
- `docs/` — project documentation and research notes

## Status

The project has a presentation-ready local dashboard supporting live source comparison for selected competitions and markets, including Win/Draw/Loss and Over/Under 2.5 goals. The scenario page is theoretical and uses editable values rather than championship outright prices.

See [`docs/release-notes.md`](docs/release-notes.md) for milestone details and [`docs/security-model.md`](docs/security-model.md) for API credential handling.

## Responsible use

Use only data that is publicly available or properly licensed. Do not commit API keys, personal information, or restricted datasets. This project is not financial advice and does not encourage participation in wagering activities.
